# 구현 메모

- `solution.py`와 `조항데이터.json`을 동일 폴더에 배치한다.
- 실행: `python solution.py "검색어"`
- JSON에서 조항 데이터를 읽는다.
- 각 조항의 **본문**에 검색어 포함 여부를 확인한다.
- 검색된 조항만 CSV로 저장한다.
- 출력 파일명: `결과_<검색어>.csv`
- CSV 헤더: `조`, `제목`, `본문`
- UTF-8(BOM) 형식으로 저장하여 엑셀에서 바로 열 수 있다.
- 저장 완료 후 검색 건수와 파일명을 화면에 출력한다.
- 검색어 미입력, JSON 오류, 파일 없음 등의 예외를 처리한다.
